# 作品集

苏州宋锦主题的儿童 AR 小游戏，以及后续的软件、工作台类项目。

## 目录结构

```
游戏/                      游戏类
  宋锦入画/                主题
    01_锦宝游苏州/          游戏
    02_宋锦小灵兽/          游戏
    03_锦衣小裁缝/          游戏
软件/                      工具与软件（预留）
工作台/                    工作台、看板类（预留）
```

新增作品时，按「类别 / 主题 / 作品」放进对应目录，一个作品一个文件夹、互不引用。

## 三个游戏

| 游戏 | 玩法 | 技术形态 |
|---|---|---|
| [01_锦宝游苏州](游戏/宋锦入画/01_锦宝游苏州/) | 摄像头把自己「穿」进宋锦衣裳，游苏州十个场景 | 全屏 video 舞台 + 云端逐帧重绘 |
| [02_宋锦小灵兽](游戏/宋锦入画/02_宋锦小灵兽/) | 十只纹样小兽（龟背、云纹、盘绦…）「长」在身上，跟着孩子动 | 摄像头 + 手部/姿态识别，视觉模型跑在本地（wasm），画面不出设备 |
| [03_锦衣小裁缝](游戏/宋锦入画/03_锦衣小裁缝/) | 挑料子、配花纹，给自己做一身宋锦衣裳 | PWA（可装到桌面、离线可用），单文件应用 |

## 怎么跑起来

三个游戏都是纯前端静态页面，**不需要安装、不需要后端**：

```bash
# 任意静态服务器都行，例如
python -m http.server 8080
# 然后浏览器打开 http://localhost:8080/游戏/宋锦入画/01_锦宝游苏州/
```

注意两点：

1. **必须走 http(s) 协议**，直接双击 `index.html` 打不开摄像头（浏览器安全限制）。
2. **要用摄像头**，所以必须有 HTTPS 或 localhost。

## 关于 API Key

第一个游戏用到了 Xmax 的云端重绘服务。仓库里**不含任何密钥**，每个使用者需要自己到
[platform.xmaxai.com](https://platform.xmaxai.com) 申请一个 Key，在游戏的「设置」里填入。
Key 只存在自己的浏览器本地，不会上传，也不会跟着代码走。

详见 [SECURITY.md](SECURITY.md)。
