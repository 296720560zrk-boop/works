# 锦宝游苏州 · 项目卡

> 新建任务时把工作空间选到这个目录：
> `F:\游戏项目\宋锦入画\01_锦宝游苏州`

## 身份

- 游戏名：锦宝游苏州（副标题：宋锦 · 苏州）
- 入口文件：`index.html`
- 技术形态：摄像头 / 全屏 video 舞台 + `sdk\`（AR 能力）、样式 `chuanyue.css`、逻辑 `chuanyue.js`
- 可加到 iPad 主屏幕全屏运行（图标名「锦宝」）

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 入口，含舞台、HUD、面板结构 |
| `chuanyue.js` | 主逻辑（约 55KB） |
| `chuanyue.css` | 全部样式（约 33KB） |
| `assets\` | 地图、服装等图片 |
| `sdk\` | 外部依赖（含 chunks），不要手动改 |
