# 锦宝游苏州

摄像头把自己「穿」进宋锦衣裳，在苏州十个场景里逛一圈。

- 评弹书场、园林水榭、月洞花墙、山塘集市、织造作坊、山塘灯会、河畔人家、临窗书房、临水厅堂、古戏台
- 每个场景有一段国风过场字幕，并自带三条动作提示（点画面或按 `T` 轮换）
- 键盘：`1`–`9`、`0` 切场景，`P` 拍照

## 运行

```bash
python -m http.server 8080
# 打开 http://localhost:8080/
```

需要摄像头，所以必须走 http(s) 或 localhost，不能双击打开。

**首次使用要在「设置」里填自己的 Xmax API Key**（从 [platform.xmaxai.com](https://platform.xmaxai.com) 获取）。
Key 只保存在本机浏览器，仓库里没有。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 入口：舞台、HUD、面板结构 |
| `chuanyue.js` | 主逻辑 |
| `chuanyue.css` | 全部样式 |
| `assets/` | 地图、服装素材 |
| `sdk/` | 第三方依赖（AR / 音视频），不要手改 |

## 隐私

摄像头画面会送到云端做逐帧重绘，这是本游戏能「换装换场景」的前提。
自建部署给孩子玩时，建议在开场加一句说明：画面用于实时生成、是否留存由服务方决定。
