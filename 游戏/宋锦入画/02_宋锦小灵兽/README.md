# 宋锦小灵兽

十只宋锦纹样化成的「小兽」，落在孩子头顶、肩膀、胸前，跟着动作一起动。

- 龟背纹、云纹、盘绦纹、球路纹、八达晕……每一只配一句祝福的童谣式解说
- 靠位置跟随、弹簧迟滞、接触阴影、色温匹配，把「贴上去」做成「长在身上」
- 摄像头 + 手部/姿态识别，视觉模型跑在本地（`vendor/wasm`），画面不出设备

## 运行

```bash
python -m http.server 8080
# 打开 http://localhost:8080/
```

需要摄像头，必须走 http(s) 或 localhost。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 入口 |
| `app.js` | 主逻辑（小兽、锚点、合成） |
| `style.css` | 样式 |
| `sfx.js` | 音效 |
| `ledger.js` | 使用记录 / 导出 |
| `vendor/` | 第三方视觉模型与运行库 |
| `assets/` | 小兽贴片素材 |
